# Regime-Dependent Transferability of Machine Learning Forecasts in an Emerging Equity Market: Evidence from VN30 Walk-Forward Benchmarks

## Proposal-To-Repository Alignment Audit

This audit checks the current regime-transferability proposal against existing local repository artifacts only. It does not add data, change provider behavior, change model/runtime/benchmark logic, edit DOCX/PDF outputs, or promote any final-window result into selection evidence.

## Alignment Verdict

The proposal is viable as a bounded diagnostic paper if it is framed as evidence of regime-dependent transferability rather than proof of economic regime existence. The strongest supported claims are validation-window diagnostics for h40 latent regimes: regime information gain is positive, global-model accuracy differs across latent regimes, and transfer matrices show non-identical cross-regime behavior. The current validation distance tests do not support the claim that transferability decreases as regime distance increases.

The main bounded h40 benchmark result remains Logistic L2 using the C-closest reference feature set, validation-selected threshold 0.55, final accuracy 61.63%, and full 30-stock coverage. The latent-regime transfer matrices use an h40 Logistic L2 reference with fixed 0.50 threshold for comparability; this is a diagnostic layer and does not replace the main benchmark row.

## Evidence Snapshot

- Benchmark scope: 75 planned/attempted variants, 74 run, 0 failed, 0 skipped, 1 not recommended; 1,868 planned/attempted model-horizon rows and 1,864 successful rows.
- Main h40 benchmark result: Logistic L2, C-closest reference feature set, validation-selected threshold 0.55, final accuracy 61.63%, 4,074 final rows, 30/30 stock coverage.
- Latent-regime setup: train-only 3-regime GaussianMixture, h40, 259 train unique timestamps, lagged return/volatility state vectors plus lagged breadth where available.
- Primary latent-regime evidence window: validation. Final-window latent-regime outputs are descriptive scoring-only.
- Validation RIG: 0.403333. Descriptive final RIG: 0.429032.
- Regime-conditional validation accuracy gap: 0.085666. Chi-square statistic: 121.98. p-value: 3.25e-27.
- Validation TRR-vs-RD Pearson correlation: 0.0651101, p = 0.902473.
- Validation TG-vs-RD Pearson correlation: -0.0255052, p = 0.961751.
- Bull/bear/sideway router: 63.33% final h40 accuracy is descriptive final-window context only and is not claim-eligible.
- Soft voting: near 62.00% final h40 accuracy is descriptive cooperation context only and is not claim-eligible.
- Stacking and meta-model rows with high validation and poor final transfer are transfer-failure and overfit-risk evidence.
- KNN-support is diagnostic only. GARCH is diagnostic only. Market-index evidence is context only.

## Paper Sections That Must Be Revised

- Abstract: keep the benchmark and h40 result, but add the latent-regime validation results only as diagnostics. State that H4 is not supported.
- Research Gap and Contribution: frame the new contribution as a proposal-to-evidence diagnostic and latent-regime transfer audit, not as proof of regimes.
- Regime-Aware Transfer Diagnostics: separate the existing bull/bear/sideway router evidence from the train-only latent-regime analysis. The 63.33% router result remains descriptive final-window context only.
- Hypotheses Section: mark H1 and H2 as diagnostically supported, H3 as mixed/partial, and H4 as unsupported by current validation distance tests.
- Metrics Section: distinguish the main h40 benchmark threshold 0.55 from the fixed 0.50 threshold used in latent-regime transfer matrices for comparability.
- Results Section: report validation RIG, regime-conditional accuracy gap, chi-square test, TRR/TG matrix behavior, and the RD tests. Do not promote descriptive final-window RIG or router scores.
- Limitations: add that latent regimes are reconstructed from local lagged state features and are not external economic labels.

## Claim Boundary

- The benchmark is preliminary and diagnostic evidence, not proof of regime existence.
- The main bounded result remains h40 Logistic L2 using the C-closest reference feature set, threshold 0.55, final accuracy 61.63%, and full 30-stock coverage.
- Final-window outputs, including descriptive final RIG, router rows, and cooperation rows, are scoring-only context and not selection evidence.
- No result in this audit supports trading readiness, profitability, investment advice, live deployment, final65, or generalization beyond the reported VN30 evidence.
- Market-index evidence remains context only and cannot substitute for stock-level VN30 evidence.
