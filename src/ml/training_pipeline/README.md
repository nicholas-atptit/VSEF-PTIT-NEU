# Legacy & Experimental Training Pipelines

**Important: The scripts in this directory are experimental and are NOT part of the active production pipeline.**

The active ML architecture is centralized around `DualModelTrainer` and its supported manifest-driven algorithms (CART, LSTM, BiLSTM).

Files here (CNN, TFT, RL allocators, ONNX exports) are retained for historical research and reference but are not currently maintained or used by the main application endpoints.
